# Changelog

All notable changes to RunLedger Community will be documented in this file.

This project follows the versioning policy in [docs/versioning-policy.md](docs/versioning-policy.md).

## [v1alpha1] - 2026-08-07

Initial alpha release of RunLedger Community as a self-hosted AI operations control plane.

### Added

- one-click demo mode with replay-safe `Full Simulator` and `Quick Seed` flows
- guided demo scenarios, sales engineering walkthrough, and visual regression fixture manifest
- backup operations surfaces including configuration, history, restore drills, and operator docs
- Kafka/Redpanda export foundations, streaming helpers, and demo-oriented event fanout flows
- OTLP collector guidance, metrics/log support groundwork, and local observability profile docs
- advanced routing, gateway health, MCP governance, and tool policy surfaces across the product
- local deployment profiles for core, aux, backup, observability, streaming, TLS demo, and full-demo paths

### Changed

- expanded simulator coverage across apps, teams, team models, tools, approvals, email, backups, traces, intents, outcomes, and savings categories
- refreshed README and docs to reflect current product surfaces, deployment profiles, and demo workflows
- improved local operator guidance for backup/restore, desktop agent setup, hardening, and gateway scale topics

### Notes

- `v1alpha1` is an alpha cut intended for self-hosters, evaluators, and internal demos.
- Enterprise-only roadmap items remain tracked separately and are not part of this alpha commitment.
