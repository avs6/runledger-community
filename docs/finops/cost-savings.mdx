The Cost & Savings page is the primary FinOps drilldown for optimization. It explains where spend is concentrated, how much RunLedger saved, and which workspace, workflow, agent, model, or tool is the next best optimization target.

## What the page shows

- **Spend versus saved** - actual observed spend alongside realized savings
- **Optimization rate** - percent of spend avoided through optimization behavior
- **Dimension breakdown** - workspace, workflow, application, user, agent, model, tool, or time
- **Savings attribution** - cache hits, smart routing, local models, prompt compression, duplicate detection, and tool optimization
- **Budget context** - workspace budget rollups alongside savings analysis
- **Next target recommendation** - the highest-value optimization candidate in the current window

## Best used for

- explaining where savings are already working
- finding which business segment should be optimized next
- comparing optimization value across workspaces or workflows
- validating whether budgets and routing changes are actually improving unit economics
