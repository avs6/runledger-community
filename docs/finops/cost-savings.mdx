The Cost & Savings dashboard shows how much you're saving through RunLedger's optimization features, broken down by category and tracked over time.

## Key features

- **Savings breakdown** — see savings from exact cache, semantic cache, prompt compression, intelligent routing, and tool filtering.
- **Realized vs projected** — compare actual measured savings against projected estimates.
- **Trend charts** — track savings over time with daily and monthly rollups.
- **Optimization opportunities** — see recommendations for further savings with projected impact.
- **Scoped views** — filter by workspace, model, agent, or time range.

## Savings categories

| Category | Source |
|---|---|
| Exact cache | Repeated identical requests served from cache |
| Semantic cache | Semantically similar requests served from cache |
| Prompt compression | Tokens saved by compressing prompt content |
| Intelligent routing | Cost savings from routing to cheaper models when quality allows |
| Tool filtering | Tokens saved by removing irrelevant tools from context |
