The onboarding wizard walks new users through connecting their first AI application to RunLedger, with integration-specific instructions and live health status.

## Key features

- **9 integration paths** — LiteLLM, Open WebUI, OpenHands, LangGraph, Claude Code, Codex, Cursor, Windsurf, and Devin.
- **Step-by-step instructions** — each integration has 3 focused setup steps.
- **Copyable config snippets** — ready-to-paste configuration for each integration.
- **Health badges** — live Connected/Pending status on each setup step.
- **Completion checklist** — track progress through org creation, workspace setup, API key generation, config, test request, and first run.

## Wizard steps

1. Create organization and workspace
2. Choose your integration
3. Generate an API key
4. Copy the integration config
5. Send a test request
6. View your first run
7. Enable a budget alert
