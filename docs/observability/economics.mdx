The Economics Overview page is the bridge into RunLedger's cost-analysis workflow. It is not the deepest drilldown itself. Instead, it helps you answer:

- Which workflows are now expensive?
- Did a version change worsen cost or latency?
- What notes or rollout events explain the shift?
- Which deeper page should I open next?

## What belongs here

- **Top workflows by cost** - highest-cost feature tags that deserve deeper inspection
- **Version compare** - cost, token, and latency comparison between two rollout versions
- **Regressions** - last 7 days versus prior 7 days
- **Annotations** - release notes and cost-change context
