The Model Usage page explains which models are actually being used in live traffic and what that means for cost, latency, cache behavior, routing, and observed quality.

## What the page shows

- **Scope-aware usage** - workspace, organization, or platform view depending on role
- **Model concentration** - which models are taking the most traffic and spend
- **Timeline mix** - how model families shift over time
- **Route distribution** - which gateway routes and providers are carrying the load
- **Cost / latency / quality comparison** - compare models on real traffic rather than static catalog metadata
- **Best-value signals** - spot which models appear to deliver better quality-for-cost tradeoffs

## Best used for

- understanding whether routing is spreading traffic as intended
- spotting high-cost or high-latency model lanes
- comparing local versus hosted model behavior
- validating whether AI Hub and Provider Profiles are showing up in real usage
