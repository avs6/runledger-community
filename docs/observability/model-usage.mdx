title: "Model Usage"
description: "Detailed model-level usage analytics — request counts, token consumption, cost distribution, latency, and error rates per model and provider."
---

The Model Usage dashboard gives you a per-model breakdown of how your AI infrastructure is being used, helping you spot cost concentration, under-utilized models, and performance outliers.

## Key features

- **Per-model metrics** — request count, total tokens, cost, average latency, and error rate.
- **Provider breakdown** — see which providers are serving each model.
- **Cost distribution** — donut chart showing spend concentration across models.
- **Time-series trends** — track model usage changes over time.
- **Scoped views** — filter by workspace, time range, or agent.
