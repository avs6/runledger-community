The Engineering dashboard gives backend and platform teams a real-time view of system health, performance, and optimization effectiveness.

  <img src="/images/engineering.png" alt="Engineering Dashboard" />
</Frame>

## Key metrics

| Card | What it shows |
|------|---------------|
| Total Requests | Provider calls in the time window |
| Avg Latency | Mean response time across all calls |
| P95 Latency | 95th-percentile response time |
| Error Rate | Percentage of calls that returned an error |
| Input / Output Tokens | Total token consumption |
| Total Cost | Aggregate spend in USD |
| Cache Hit Rate | Percentage of calls served from cache |

## Prompt Lifecycle Pipeline

A horizontal pipeline showing how requests flow through optimization stages:

```
Received → Optimized → Cached → Routed → Completed → Errored
```

Each stage shows a count and percentage relative to total requests.

## Cost Breakdown

Two-dimensional cost analysis:

- **By Model** — cost attribution across all models used in the window
- **By Provider** — cost attribution across providers (OpenAI, Anthropic, Ollama, etc.)

## Quality Funnel

Visualizes the pass-through quality of your AI pipeline:

| Stage | Description |
|-------|-------------|
| Total | All requests received |
| Completed | Requests that returned a response |
| Cached | Responses served from cache (exact or semantic) |
| Optimized | Requests where token optimization was applied |

## API

```
GET /analytics/engineering?from=&to=
```

Returns `EngineeringMetrics` with all KPIs, lifecycle stages, cost dimensions, and quality funnel in a single response. See the [API reference](http://localhost:8201/reference) for the full schema.
