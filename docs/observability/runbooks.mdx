RunLedger auto-generates runbooks for agent runs that are expensive, failed, or triggered policy actions. Each runbook answers: what happened, why it cost so much, which model and tools were used, what failed, and what to change next.

## Key features

- **Auto-generated summaries** — created for expensive, failed, or risky runs.
- **Severity classification** — critical, warning, and info levels.
- **Export** — download as markdown or JSON.
- **Generate from run ID** — create a runbook for any specific run on demand.
- **Linked navigation** — jump to the run in [Request Explorer](/observability/request-explorer) or view the full run detail.

## Runbook contents

Each runbook includes:
- What happened (timeline and outcome)
- Cost breakdown and why it was expensive
- Model selection and routing decisions
- Tools used and their results
- Policy decisions that occurred
- What failed and root cause
- Recommended next steps
