The Analytics Users area answers a simple question: **which end users are driving spend, and is that spend healthy?**

Use it when you want to find:

- heavy spenders
- new users ramping quickly
- anomalous spend patterns
- which models and features one user is consuming over time

## What the list page shows

- **Top spenders** - end users ranked by spend
- **Cohort tiers** - P0 to P3 distribution by spend band
- **Anomaly flags** - user spend anomalies surfaced from the nightly worker
- **Quick segmentation** - all, heavy, anomalous, and new-this-week views

## What the detail page shows

- **Per-user totals** - spend, runs, calls, and average cost per run
- **Spend over time** - how the user's activity changes across the selected window
- **Models used** - which models are driving that user's cost
- **Features used** - which workflows or feature tags are responsible
- **Workflow bridges** - direct pivots into Request Explorer, Request Flow, and Outcomes & ROI
