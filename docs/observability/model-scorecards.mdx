Model Scorecards help you compare models on more than cost alone. They bring quality, latency, reliability, cache behavior, and recommendation hints into one model-by-model surface.

## What the page shows

- **Cost and call volume** - total cost, call count, and average cost per call
- **Latency posture** - average and P95 latency
- **Reliability** - error rate and retry rate
- **Cache behavior** - cache hit rate
- **Quality signals** - average quality score, eval score, and user feedback score
- **Risk signals** - hallucination flags and acceptance rate
- **Recommendation hints** - guidance for routing or model selection based on the observed data
- **Trend drilldown** - per-model trend view for quality and error rate over the selected window

## Best used for

- comparing two candidate models before changing routing
- validating whether a cheaper model is still holding the quality bar
- spotting models with hidden reliability issues
- identifying where evaluation or replay work is needed next

## Workflow fit

Use this page after:

1. `Model Usage` shows where spend and traffic are concentrated.
2. `Request Flow` or `Request Explorer` identifies which routes are involved.
3. `Model Scorecards` compares the model candidates directly.
4. `Evaluation Studio` or `Replay Lab` provides deeper proof before a routing change.

## Organization, Gateway & Observe Context (Model Scorecards)

The Model Scorecards page surfaces three posture cards:

- **Organization & Access Context** (blue) — workspace, API keys, hub models
- **Gateway & Routing Context** (violet) — providers, routes, guardrails, cache configs, rate limits
- **Observe & Runtime Context** (cyan) — runs 30d, provider calls, distinct models, cost 30d

```bash
curl -H "Authorization: Bearer $KEY" \
  $HOST/analytics/optimization-org-gateway-posture

curl -H "Authorization: Bearer $KEY" \
  $HOST/analytics/optimization-observe-posture

curl -H "Authorization: Bearer $KEY" \
  $HOST/analytics/optimization-finops-posture
```

### FinOps & Budget Context

Model Scorecards also displays a **FinOps & Budget Context** card (emerald) showing active budgets, total limit, 30d spend, billing periods, and chargeback rules with drill-through to Budgets, Billing Periods, Chargeback, and Cost & Savings.

### Build & Improve Loop

Model Scorecards also displays a **Build & Improve Loop** card (rose) via `GET /analytics/build-internal-posture` showing playground sessions, workflows, eval experiments, prompts, and replay experiments with drill-through to Playground, Workflows, Evaluation Studio, Optimization, and Simulator.
