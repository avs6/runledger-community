**RunLedger is an open-source Agent FinOps Control Plane.**

It turns LangChain, LangGraph, OpenAI, Anthropic, and any OpenTelemetry-instrumented agent into trace-linked usage accounting, provider invoice reconciliation, internal chargeback, budget enforcement, economics-aware routing, and outcome-to-cost visibility.

Tracing tools tell you *what happened*. RunLedger tells you *what it cost, who pays, whether you're over budget, how it reconciles against the provider invoice, and what the ROI was.*

---

## The problem it solves

Every team shipping AI agents in production hits the same wall:

  <Card title="Chargeback is guesswork" icon="circle-question">

## What's built

<CardGroup cols={2}>
  <Card title="Provider metering" icon="gauge-high">
    Input vs output tokens (plus cached input) mapped to provider pricing so your internal numbers match the invoice.
  </Card>
  <Card title="Budget enforcement" icon="shield-check">
    Set spend limits per workspace/user/feature. Block or throttle automatically.
  </Card>
  <Card title="Invoice reconciliation" icon="receipt">
    Import billing exports from OpenAI, Anthropic, Google. Match against internal calls by request ID. Export signed dispute packages.
  </Card>
  <Card title="Chargeback" icon="building">
    Attribute cost to tenants, features, or teams with shared-cost policies and approval workflow.
  </Card>
  <Card title="Model gateway" icon="network-wired">
    OpenAI-compatible proxy with prompt caching, provider fallback, and outcome-aware routing policies.
  </Card>
  <Card title="Outcome & ROI ledger" icon="chart-line">
    Tie spend to business outcomes: cost-per-success, ROI by workflow, success rate trends.
  </Card>
</CardGroup>

## Ingestion paths

| Path | When to use |
|------|-------------|
| **RunLedger SDK** | Best path — budget enforcement, `rl.score()`, prompt fetch, propagation headers |
| **OTLP direct** | Already emit OTel / OpenInference; zero instrumentation change |
| **OTLP via Collector** | Production — batching, retry, attribute enrichment |
| **Model Gateway** | OpenAI base_url swap — works for any OpenAI-compatible client |

All paths normalise into the same domain model: `AgentRun → Span → ProviderCall / ToolCall`.
