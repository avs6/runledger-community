**RunLedger is an open-source Agent FinOps control plane.** It sits between your agents and every model
provider — OpenAI, Anthropic, Gemini, Mistral, Cohere, and any self-hosted or OpenAI-compatible endpoint —
and turns raw inference traffic into trace-linked cost accounting, budget enforcement, outcome-to-cost
visibility, and active token optimization.

> Tracing tools tell you *what happened.*
> RunLedger tells you *what it cost, who pays, whether you're over budget, what the ROI was — and how to
> spend fewer tokens next time.*

## The problem it solves

<CardGroup cols={2}>
  <Card title="Spend explodes" icon="fire">
    A retry loop or runaway agent silently burns through the API budget overnight — nobody notices until the invoice lands.
  </Card>
  <Card title="Attribution is guesswork" icon="circle-question">
    Cost can't be tied to a tenant, user, or feature without custom instrumentation.
  </Card>
  <Card title="Routing ignores economics" icon="route">
    Models are chosen for capability, never for cost-per-outcome.
  </Card>
  <Card title="No audit trail" icon="file-invoice">
    Nothing links internal metering back to the exact agent run that generated the spend.
  </Card>
</CardGroup>

RunLedger closes all of these in one self-hosted control plane — no vendor lock-in, no data leaving your
infrastructure, no GPU required.

invoice reconciliation, chargeback, SSO/SCIM, warehouse export, and BYOK — see the
