---
title: "Org Profile"
description: "Org-admin profile page for the active organization."
---

**Org Profile** is the active organization's self-service page. It is visible to org admins and platform admins when they are operating inside an organization.

Use Org Profile when you want to change the organization you are currently working in, not the full platform-wide organization lifecycle.

## Common Actions

- Rename the active organization.
- Review organization metadata.
- Confirm which organization the top bar breadcrumb is showing.

After a rename, the dashboard session updates `tenant_name`, so the top bar breadcrumb reflects the new name immediately.

## Organizations vs Org Profile

| Page | Visible To | Purpose |
|---|---|---|
| **Organizations** | Platform admins | Platform-wide lifecycle: list, create, edit status/plan, delete orgs |
| **Org Profile** | Org admins and platform admins | Active-org profile and rename |

Org admins do not see the platform-wide Organizations page.
