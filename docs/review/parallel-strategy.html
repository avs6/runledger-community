Ground rules for every agent

Isolation

One stream = one worktree = one branch (review/<stream>), cut from the review/base branch made in Wave 0. Never work in the main checkout; other sessions use it.

File ownership

Each stream owns the files in the ownership table. To change another stream's file, keep the edit small and additive, and list it under "cross-stream edits" in the PR body.

Migrations

At most one Alembic revision per stream, named <stream>_<slug>. The integrator re-points down_revision at merge time, so the chain stays linear.

Single writer for the review

Only the Wave 3 integrator edits runledger-review.html. Streams list the resolved IDs (with their section) in the PR body.

Done bar (AGENTS.md)

Backend → UI → CRUD → docs → scripts (with asserts) → examples. Postman is skipped (the project has none). Ruff, mypy, pytest, tsc and eslint must be clean.

Environments

Unit tests in the worktree only. The one Docker stack (ports 8201/3201) belongs to the integrator. Never touch the X230 (production). No commits outside the stream's branch.
