description: "Configure routing strategies, tag filters, and fallback chains across providers and tiers."

Each model alias can have multiple routes. When a request arrives, RunLedger selects a route by policy, tag filters, region preference, and health state, then falls back if the chosen provider fails.

## Fallback behavior

Routes carry a `priority` where lower numbers are tried first. On a transient provider failure the gateway retries and then moves to the next eligible route. That means provider failures are absorbed by the fallback chain and hidden from clients unless every eligible route fails.

## Routing strategies

Routing strategies are configurable through both the API and the Gateway UI.

| Policy | Purpose |
|---|---|
| `manual` | Priority-order routing |
| `cost_optimized` | Cheapest route above a quality floor |
| `latency_optimized` | Lowest recent p95 latency |
| `quality_optimized` | Highest average quality score |
| `weighted` | Weighted traffic split |
| `canary` | Gradual rollout to one route |
| `ab_test` | Experiment split with significance analysis |
| `budget_aware` | Fallback alias when budget threshold is hit |
| `complexity_based` | Branch by request complexity |
| `outcome_optimized` | Lowest cost per successful outcome |

## Tag-based routing and exclusion flows

Routes support both `required_tags` and `excluded_tags`. This allows:

- **Tier routing** such as `tier:cheap`, `tier:mid`, and `tier:frontier`
- **Provider exclusion** such as excluding `provider:openai` or `provider:anthropic`
- **Safety or residency slices** such as excluding `region:eu` or `data:restricted`

Routing groups can also contribute default tags for untagged traffic, which makes the tier and provider exclusion flow work even when callers do not pass custom headers.

## A/B testing validity

Production A/B testing uses:

- per-variant request counts
- success and error rates
- significance testing with a configurable `significance_threshold`
- minimum sample enforcement before a winner can be promoted

Winner promotion for A/B tests is blocked until significance and sample requirements are met.
