A route maps an alias to a **provider** + **target model**. Hosted and self-hosted models are configured
identically and metered the same way.

## Supported providers

| Provider | Access |
|---|---|
| OpenAI (gpt-4o, gpt-4o-mini, o1, o3-mini, …) | SDK · Gateway |
| Anthropic (Claude Opus, Sonnet, Haiku, …) | SDK · Gateway |
| Google Gemini | SDK · Gateway |
| Mistral | SDK · Gateway |
| Cohere | SDK · Gateway |
| Self-hosted & OpenAI-compatible (Ollama, vLLM, Groq, Azure, Bedrock, Vertex) | Gateway |

## Self-hosted & local models

Local runtimes stay **external** — RunLedger never bundles them; it points at their base URL. Configure
Ollama or vLLM as an ordinary route:

```bash
POST /gateway/routes
{
  "alias": "cheap",
  "provider": "ollama",
  "target_model": "llama3.1:8b",
  "base_url": "http://host.docker.internal:11434/v1"
}
```

Set `OLLAMA_BASE_URL` / `VLLM_BASE_URL` in the environment for the default endpoints. Because they're
OpenAI-compatible, they route, cache, fall back, and meter like any hosted provider. See
[Self-Hosted & Local Models](/optimization/local-models).

## Adding a model

Add a new model by inserting a row into `provider_pricing` — **no code change required**. The
[pricing engine](/finops/pricing) then meters it automatically.

## API keys

Each route references an env var holding the provider key (`api_key_env_var`, e.g. `OPENAI_API_KEY`), so
keys stay in your environment / secret store, never in the database.

## Financial posture

Each provider profile is a valid budget scope (`scope_type=provider_profile`). The financial posture
endpoint returns budget, override, billing, and chargeback summaries for a single profile:

```bash
GET /analytics/provider-profile-finops-posture?profile_id=<uuid>
```

Response:

```json
{
  "workspace_id": "...",
  "profile_id": "...",
  "provider": "openai",
  "model": "gpt-4o",
  "budgets": {
    "budget_count": 2,
    "active_budget_count": 1,
    "total_limit_usd": 500.0,
    "breach_count": 0
  },
  "overrides": {
    "override_count": 1,
    "active_override_count": 1
  },
  "billing": {
    "billing_period_count": 3,
    "open_billing_periods": 1
  },
  "chargeback": {
    "chargeback_rule_count": 2
  }
}
```

The Provider Profiles page links directly to Budgets, Budget Detail, Budget Overrides, Billing Periods,
Billing Period Detail, and Chargeback for each profile, with a per-profile FinOps Posture modal
showing the summary above.
