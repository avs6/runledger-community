Alert rules watch key control-plane and gateway metrics so operators hear about spend spikes, degraded model availability, or rising gateway overhead within minutes.

## Key features

- **Metric-threshold rules** with a metric, comparator, threshold, and window.
- **Gateway-aware checks** including model availability and p95 gateway overhead.
- **Channels** for Slack, webhook destinations, and optional email to workspace admins.
- **Scheduled evaluation** by the background worker on a recurring cadence.

## Example rules

| Rule | Fires when |
|---|---|
| Spend spike | Spend velocity exceeds threshold |
| Success-rate drop | Error rate or score crosses threshold |
| Model availability | Healthy route ratio drops below threshold |
| Gateway overhead | p95 gateway overhead rises above target |

## Gateway acceptance monitoring

The gateway-specific metrics are useful for production acceptance checks:

- `model_availability`
  Use a threshold like `< 1.0` or `< 0.95` to alert when healthy route coverage drops.
- `gateway_overhead_p95`
  Use a threshold in milliseconds to enforce your gateway overhead budget.

Configure rules on **Control Plane -> Alert Rules** and notification channels on **Control Plane -> Integrations**.
