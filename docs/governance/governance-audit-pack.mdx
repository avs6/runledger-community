---

The governance audit pack bundles everything an auditor or compliance team needs into a single exportable report — who used which models, what policies were enforced, which approvals happened, and what data was captured or redacted.

## Key features

- **Exportable evidence bundle** — generate a pack covering any date range, org, or workspace.
- **Comprehensive coverage** — model usage, route selections, policy enforcements, approval records, data capture policies, and budget alerts.
- **Compliance summary** — a checklist of governance controls with pass/fail status.
- **Export formats** — JSON and CSV for integration with GRC tools.

## What's included

| Section | Details |
|---|---|
| Model usage | Who used which model, when, token counts |
| Policy enforcements | Which policies fired, action taken, affected requests |
| Approvals | Request type, requester, decision, timestamp |
| Data capture | Active capture policies, privacy modes, retention |
| Budget alerts | Over-budget events, severity, affected scope |
| Compliance summary | Governance controls checklist |
