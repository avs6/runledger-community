RunLedger is configured through environment variables (see [`.env.example`](https://github.com/avs6/runledger-community/blob/master/.env.example)).
This page is the reference for the ones you'll actually touch.

## Core

| Variable | Default | Notes |
|---|---|---|
| `SECRET_KEY` | — | **Required.** 32-byte hex; signs tokens and the ledger. |
| `ADMIN_SECRET` | falls back to `SECRET_KEY` | Guards `/admin/*` and the internal gateway/MCP endpoints that resolve API keys. |
| `DATABASE_URL` | in-compose Postgres | `postgresql+asyncpg://…` |
| `REDIS_URL` | in-compose Redis | Queue + budget hot-path. |
| `CORS_ORIGINS` | `http://localhost:3201` | Dashboard origin(s). |
| `INTERNAL_SERVICE_TOKEN` | `ADMIN_SECRET` | Shared token every optimization microservice requires on non-health requests; the API, workers, MCP gateway and context compiler send it. |
| `RUNLEDGER_INTERNAL_BIND` | `127.0.0.1` | Host address for internal ports (databases, queues, Letta, optimization microservices). Only the API, gateway, web, Caddy, MCP gateway and OTLP ports listen on all interfaces. |
| `INGEST_MAX_BATCH_EVENTS` | `1000` | Max events per `/ingest/v1/batch` request. |
| `INGEST_MAX_BODY_BYTES` | `10485760` | Max request body for ingest and OTLP routes (413 above). |
| `OTLP_MAX_DECOMPRESSED_BYTES` | `52428800` | Max size a gzip OTLP body may inflate to. |
| `OTLP_RUN_GATING` | `llm` | `llm`: only traces with an LLM/agent/tool span become runs. `all`: every trace. |
| `OTLP_RAW_RETENTION_DAYS` | `14` | Days to keep raw OTLP batches/spans, finished Kafka deliveries and resolved dead letters. `0` keeps them. |
| `PROVIDER_KEY_ENV_ALLOWLIST` | `*_API_KEY,*_PROXY_KEY,*_SERVICE_ACCOUNT_JSON` | Environment variables a gateway route may name as its provider key (globs). Platform secrets (`SECRET_KEY`, `ADMIN_SECRET`, `*PASSWORD*`, `DATABASE*`, `RUNLEDGER_*`…) are always refused. |
| `GATEWAY_BASE_URL_ALLOWLIST` | empty | Extra hosts (globs) a route created by an org admin may send server-side provider keys to, besides each provider's official host. Platform admins can set any public host. |
| `GATEWAY_TRUSTED_PROXIES` | empty | Comma-separated CIDRs of reverse proxies in front of `runledger-gateway-rs` (passed as `RUNLEDGER_GATEWAY_TRUSTED_PROXIES`). Only these peers' `X-Forwarded-For` is used as the client IP for IP ACLs; empty means the connection's peer address is always used. |
| `API_TRUSTED_PROXIES` | `172.16.0.0/12` (compose) | Passed to the API as `TRUSTED_PROXIES` (IPs or CIDRs). Only these peers' `X-Forwarded-For` is used as the client IP for pass-through IP ACLs and login rate limits; the default covers the compose network where Caddy runs. |
| `RUNLEDGER_CONTROL_PLANE_TIMEOUT_MS` | `30000` | gateway-rs ceiling for its calls to the control plane (preflight, finalize, route results, events). Connections time out after 5 s; the bridged provider call uses the step's timeout plus 5 s, and background mirror calls 300 s. |
| `OTLP_METRIC_RETENTION_DAYS` | `395` | Days to keep daily OTLP metric rollups. `0` keeps them. |
| `COMPOSE_PROFILES` | empty | Docker Compose only: `streaming` also starts the bundled Redpanda broker and console for Kafka export. |
| `OTLP_INACTIVITY_TIMEOUT_MINUTES` | `15` | OTLP runs with no span activity this long are closed as cancelled. |
| `INGEST_SIGNATURE_TOLERANCE_SECONDS` | `300` | Signed ingest: max clock skew; nonces are remembered twice as long. |
| `EGRESS_PRIVATE_ALLOWLIST` | `runledger-redpanda` | Hosts that webhooks, Slack and Kafka may reach even on private addresses. |
| `EGRESS_ALLOW_PRIVATE` | `false` | Allow tenant destinations on private/internal addresses (trusted networks only). |
| `BUDGET_THROTTLE_RPM` | `10` | Requests per minute the gateway still admits for a `throttle` budget past its limit. |

Payload capture is **off by default** and is controlled by the SDK's `privacy_mode` argument (not a
server env var) — see [Data retention](/governance/retention).

## Ports

Host ports are chosen to avoid clashes with other local products. Override any with the `*_PORT` variables in `.env`.

| Variable | Default | Service |
|---|---|---|
| `WEB_PORT` | 3201 | Dashboard |
| `API_PORT` | 8201 | API control plane |
| `GATEWAY_RUNTIME_PORT` | 8210 | Rust gateway |
| `POSTGRES_PORT` | 5432 | Postgres |
| `REDIS_PORT` | 6379 | Redis |
| `QDRANT_HTTP_PORT` / `QDRANT_GRPC_PORT` | 8202 / 8203 | Qdrant |
| `EMBEDDING_PORT` | 8204 | Embedding service |
| `SEMANTIC_CACHE_PORT` | 8205 | Semantic cache |
| `MCP_PORT` | 8206 | MCP gateway |
| `CONTEXT_COMPILER_PORT` | 8207 | Context compiler |
| `RERANKER_PORT` | 8208 | Reranker |
| `COMPRESSION_PORT` | 8209 | Compression |
| `ROUTER_PORT` | 8105 | Intelligent router |
| `MEMORY_PORT` | 8211 | Memory service |
| `KG_PORT` | 8212 | Knowledge graph |
| `SKILL_PORT` | 8213 | Skill registry |
| `LETTA_PORT` | 8214 | Letta |
| `FLYWHEEL_PORT` | 8215 | Flywheel |

MinIO (9010/9011), Redpanda (19092/18082), Redpanda Console (19091), OTel Collector (4317/4318), and Caddy (3443/8443) use fixed ports in `docker-compose.yml`.

## Optimization layer

| Variable | Default | Notes |
|---|---|---|
| `QDRANT_URL` | in-compose Qdrant | Vector store. |
| `EMBEDDING_MODEL` / `EMBEDDING_DIM` | `bge-small-en-v1.5` / 384 | Shared embedding model of record. |
| `SEMANTIC_CACHE_THRESHOLD` | `0.95` | Similarity floor for a cache hit. |
| `RERANKER_MODEL` / `COMPRESSION_MODEL` | `flashrank` / `bert-base-multilingual` | Model choices for those services. |
| `MCP_REQUIRE_AUTH` | `true` | MCP gateway requires a RunLedger API key on every tool call. Set `false` only for isolated local development. |

## Local LLMs (external)

Ollama and vLLM are never bundled — RunLedger points at their base URL:

| Variable | Example |
|---|---|
| `OLLAMA_BASE_URL` | `http://host.docker.internal:11434/v1` |
| `VLLM_BASE_URL` | `http://vllm-host:8000/v1` |
| `LOCAL_LLM_MODEL` | `llama3.2:3b` |

## Kubernetes

On Kubernetes these are set through the Helm chart's values (secrets, `optimization.*`, `stores.*`).
See [Helm deployment](/helm) and [Configuration reference in helm.md](/helm#values-reference).
